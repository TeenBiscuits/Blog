# Checklist

# Convenciones para Mensajes de Commit

| Tipo          | Descripción                                                             | Ejemplo                                         |
| :------------ | :---------------------------------------------------------------------- | :---------------------------------------------- |
| **feat:**     | Nueva funcionalidad o característica                                    | `feat: añadir login con Google`                 |
| **fix:**      | Corrección de un bug                                                    | `fix: resolver error en validación de email`    |
| **chore:**    | Tareas de mantenimiento, cambios en configuración, dependencias         | `chore: actualizar dependencias`                |
| **docs:**     | Cambios en documentación                                                | `docs: actualizar README con instrucciones`     |
| **style:**    | Cambios de formato (espacios, punto y coma, etc.) sin afectar el código | `style: formatear código con prettier`          |
| **refactor:** | Refactorización de código sin cambiar funcionalidad                     | `refactor: simplificar lógica de autenticación` |
| **test:**     | Añadir o modificar tests                                                | `test: añadir tests unitarios para login`       |
| **perf:**     | Mejoras de rendimiento                                                  | `perf: optimizar consulta de base de datos`     |
| **ci:**       | Cambios en configuración de CI/CD                                       | `ci: añadir workflow de GitHub Actions`         |
| **build:**    | Cambios en el sistema de build o dependencias externas                  | `build: actualizar webpack a v5`                |
| **revert:**   | Revertir un commit anterior                                             | `revert: revertir commit abc123`                |
